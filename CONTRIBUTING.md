# Contributing

Thanks for your interest in FaustMod.

**This project is not accepting pull requests at this time.** External PRs will not be
reviewed or merged for now. This may change in the future.

**Bug reports and ideas are very welcome**, and they go to two different places:

- **[Open an issue](https://github.com/thepacket/faustmod/issues/new/choose)** when
  something is broken — silence where there should be sound, a block that won't compile,
  a widget that misbehaves, a patch that won't load. The bug template asks for the
  browser, the console output and (if it helps) the `.faustmod` patch.
- **[Start a discussion](https://github.com/thepacket/faustmod/discussions)** for
  everything else: questions about patching, blocks or widgets you'd like to see, and
  patches you've built and want to show off.

The project is licensed under the [GPL-3.0-or-later](LICENSE), so you're welcome to fork
it and build on it — including for your own use — as long as derivatives stay GPL.
